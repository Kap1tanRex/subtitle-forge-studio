# Темы оформления

Тема — это один файл `.sfstheme.json` в каталоге тем. Она меняет цвета
программы, а при желании и таблицу стилей Qt: скругления, отступы, рамки.

Каталог тем лежит там же, где модели и плагины — рядом с программой либо в
папке, выбранной в `Настройки → Загрузки`. Открыть его можно кнопкой
«Папка тем» в `Настройки → Интерфейс`; там же кнопка «Создать образец»
кладёт готовый файл, который останется поправить.

Тема появляется в списке сразу после того, как файл оказался в каталоге —
достаточно снова открыть настройки.

## Чем тема отличается от плагина

Плагин — это программа на Python, и включать его надо осознанно: он умеет всё
то же, что и сама программа. Тема — только данные. Худшее, что сделает
испорченная тема, — покажет некрасивое окно. Поэтому темы работают сразу и
разрешения в настройках не требуют.

## Формат

```json
{
  "name": "ocean",
  "title": "Океан",
  "author": "Имя автора",
  "version": "1.0",
  "base": "dark",
  "colors": {
    "bg_base": "#0B1A24",
    "bg_elevated": "#102A38",
    "accent": "#2BB3C0"
  },
  "qss": "QToolBar { border-bottom: 0; }"
}
```

| Поле | Что значит |
|---|---|
| `name` | Имя, под которым тема запоминается в настройках. Без него берётся имя файла |
| `title` | Подпись в списке тем |
| `author`, `version` | Необязательные, показываются под списком |
| `base` | Встроенная тема-основа: `dark`, `light`, `sepia` или `contrast`. Цвета, не указанные явно, берутся из неё |
| `colors` | Что поменять относительно основы |
| `qss` | Необязательная добавка к таблице стилей Qt. Дописывается последней, поэтому может перекрыть правила программы |

Указывать все цвета не нужно: тема из трёх строк — обычное дело. Незнакомые
ключи в `colors` пропускаются, так что тема, написанная под будущую версию,
откроется и здесь.

Файловая тема с именем встроенной перекрывает её. Это способ подправить
стандартную тему, не выдумывая ей новое название.

## Цвета

| Ключ | Где виден |
|---|---|
| `bg_base` | Основной фон окна и таблицы |
| `bg_elevated` | Панели, шапка таблицы, строка состояния |
| `bg_sunken` | Поля ввода, углубления |
| `border` | Рамки и разделители |
| `text_primary` | Основной текст |
| `text_muted` | Подписи и подсказки |
| `accent` | Акцент: рамка активного поля, направляющие |
| `accent_muted` | Фон выделенной строки |
| `success`, `warning`, `danger` | Отметки проверок качества |
| `playhead` | Курсор времени на таймлайне |
| `canvas_a`, `canvas_b` | Шахматка на месте кадра, когда видео нет |
| `guide` | Направляющие и безопасные зоны |
| `wave_fill`, `wave_rms` | Волна звука: огибающая и уровень поверх неё |

Цвет пишется как `#RRGGBB`. Если хоть один разобрать не удалось, тема
показывается в списке недоступной с указанием, где именно опечатка, — молча
пропасть она не должна.

## Акцентный цвет

`Настройки → Интерфейс → Акцентный цвет` меняет акцент поверх любой темы,
включая свою. Восемь готовых цветов и свой через палитру.

Из выбранного цвета выводятся ещё два: фон выделенной строки и цвет
направляющих. Подбирать три согласованных цвета вручную не нужно, а текст на
выделении остаётся читаемым при любом сочетании — это проверяется тестами по
обычному порогу доступности.

Чтобы вернуть цвет самой темы, выберите «Как в теме».

## Анимации

`Настройки → Интерфейс → Анимации`. Три состояния: «как в системе» (по
умолчанию), «включены», «выключены».

«Как в системе» смотрит настройку анимации Windows — ту же, которой
пользуются при укачивании от движения и на слабых машинах.

Что анимируется: появление окон, меню, подсказок и выпадающих списков,
прокрутка таблицы к выбранной реплике, вспышка при переходе к следующей
проблеме. Длительности — от 120 до 180 миллисекунд.

Плавных переходов цвета у кнопок нет: внешний вид задан таблицей стилей Qt, а
она переходов не поддерживает, в отличие от CSS в браузере. Сделать их можно
было бы, только отказавшись от таблицы стилей и рисуя каждое состояние каждой
кнопки самим — цена больше пользы.
